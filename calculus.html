Lesson 1: Introduction to Limits

A limit describes the value a function approaches as its input gets closer to a particular number.

Example:

Find lim (x → 2) (x + 3).
Substitute x = 2.
Answer = 2 + 3 = 5.

Lesson 2: Differentiation

Differentiation helps us find the rate of change of a function.

Power Rule:

If y = xⁿ, then dy/dx = nxⁿ⁻¹.

Example:
y = x³
dy/dx = 3x².

Another example:

If y = 4x² + 3x + 5,
dy/dx = 8x + 3.

Lesson 3: Integration

Integration is used to find antiderivatives and calculate accumulated quantities.

Power Rule:

∫xⁿ dx = xⁿ⁺¹/(n+1) + C, where n ≠ -1.

Example:
∫x² dx = x³/3 + C.

Important Calculus Rules

  • d/dx (constant) = 0
  • d/dx (xⁿ) = nxⁿ⁻¹
  • d/dx (sin x) = cos x
  • d/dx (cos x) = -sin x
  • ∫1 dx = x + C
  • ∫x dx = x²/2 + C
