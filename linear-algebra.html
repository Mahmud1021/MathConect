Lesson 1: Introduction to Linear Algebra

Linear Algebra is a branch of mathematics that studies vectors, matrices, linear equations and linear transformations.

It is useful in computer science, engineering, physics, statistics and many other fields.

Lesson 2: Matrices

A matrix is a rectangular arrangement of numbers in rows and columns.

Example:
A = [1 2]
    [3 4]

This is a 2 × 2 matrix because it has 2 rows and 2 columns.

Common types of matrices:

  • Row matrix: has one row.
  • Column matrix: has one column.
  • Square matrix: has equal rows and columns.
  • Zero matrix: all entries are zero.
  • Identity matrix: has ones on its main diagonal and zeros elsewhere.

Lesson 3: Matrix Addition and Subtraction

Matrices can be added or subtracted when they have the same dimensions. Perform the operation on corresponding entries.

A = [1 2] and B = [3 4]
    [3 4]         [5 6]

A + B = [4 6]
        [8 10]

Lesson 4: Matrix Multiplication

Two matrices can be multiplied when the number of columns in the first matrix equals the number of rows in the second.

Example:
A = [1 2] and B = [5]
    [3 4]         [6]

AB = [1(5) + 2(6)]
      [3(5) + 4(6)]

AB = [17]
      [39]

Lesson 5: Determinants

The determinant is a number associated with a square matrix.

For a 2 × 2 matrix:

A = [a b]
    [c d]

det(A) = ad - bc

Example:
A = [2 3]
    [1 4]

det(A) = (2 × 4) - (3 × 1)
det(A) = 8 - 3
det(A) = 5

Lesson 6: Inverse of a Matrix

A square matrix has an inverse if its determinant is not zero.

For A = [a b]
        [c d]

A⁻¹ = 1/(ad - bc) [d -b]
            [-c a]

This formula applies when ad - bc ≠ 0.

Lesson 7: Vectors

A vector is a quantity that has both magnitude and direction.

Example:
v = [3]
    [4]

Magnitude of v = √(3² + 4²)
= √(9 + 16)
= 5

Important Formulas

  • det(A) = ad - bc
  • A + B = Add corresponding entries.
  • AB is defined when columns of A = rows of B.
  • A⁻¹ = (1/det(A)) adj(A), when det(A) ≠ 0.
  • Vector magnitude = √(x² + y²).
